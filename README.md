# 今天吃什么

Windows 本机选餐小工具。把常吃的菜加入菜单，点击“帮我选一个”，由转盘随机选出一道菜。采用珐琅风格，宽窗口左右布局，窄窗口上下排列；菜单管理默认收起。

## 功能

- 等概率选餐，允许连续选到同一道菜；顶部指针、高亮和最终菜名一致。
- 添加、确认删除和本地保存菜单，支持空菜单；长名称显示完整结果，盘面放不下时提供编号对照。
- 可选按钮声、转盘轻咔嗒和短完成铃；首次默认静音，开关记住同一浏览器中的选择。
- 请求或动画失败时给出提示并恢复操作；声音不能播放时仍可选餐和管理菜单。

## 环境要求

| 项目 | 要求与验证范围 |
| --- | --- |
| 系统 | Windows；实际检查环境为 Windows 10 Pro，内部版本19045。 |
| Python | 代码要求最低 **Python 3.8**，启动脚本会检查。3.8门槛来自标准库API要求，不等于所有3.8及更新版本都已完整测试。 |
| 已测试的Python | 3.13.6完成既有功能验收；3.12.12完成启动、选餐、添加和删除的基础运行检查。无需安装完全相同的小版本。 |
| 浏览器 | 需要现代浏览器，建议Edge或Chrome；实际验证使用Edge，其他浏览器未逐一验收。 |
| 启动提示 | 使用Windows自带Windows PowerShell读取中文提示资源，无需另外安装PowerShell。 |

正式程序仅使用Python标准库、浏览器原生功能和Windows内置命令，不需要pip安装依赖。

最低版本不代表建议安装旧版本；新安装时建议选择仍受Python官方维护、且适合当前Windows的Python 3版本。可从 https://www.python.org/downloads/windows/ 下载，安装时包含Python Launcher，并勾选将Python加入PATH。安装后重新打开命令提示符，执行 `py -3 --version`（或 `python --version`）检查版本。

本工具不是EXE，不会自动安装Python。新电脑必须先准备环境；现有电脑测试通过不等于新电脑无需安装。

## 获取代码和首次启动

1. 从 [v1.0.0 发布页](https://github.com/ITer99/what-to-eat-vibecoding/releases/tag/v1.0.0) 下载源码运行包 `what-to-eat-vibecoding-v1.0.0.zip`，解压到有写入权限的文件夹。也可从 [公开仓库](https://github.com/ITer99/what-to-eat-vibecoding) 的 Code → Download ZIP 获取代码，或使用 Git 克隆。
2. 同一文件夹应包含：`start.bat`、`startup-messages.json`、`app.py`、`index.html`、`wheel.js`、`sound.js`、`sound-data.js`。
3. 双击 `start.bat`，保持启动窗口打开。浏览器通常会自动打开；未打开时，把窗口里 `URL:` 后的完整地址复制到浏览器。
4. 没有菜单文件时，首次生成五道默认示例菜：牛肉面、饺子、炒饭、鸡肉饭、麻辣烫。展开“管理菜单”即可换成自己的候选。之后读取保存的菜单，不在每次启动时恢复默认。
5. 点击“帮我选一个”，等转盘停稳后查看完整菜名。选餐期间不能再次选餐、添加或删除；仍可展开菜单查看。

不要在压缩包内直接运行，也不要双击 `index.html`。每次重新启动会分配新端口，请使用本次打开的页面。

## 菜单和声音

添加会去掉名称首尾空格，拒绝空白或完全同名。删除前会确认完整名称，可以取消。增删保存成功后才更新列表；删除当前结果会清除旧结果，删除其他菜保留结果。删空后不能选餐，重新添加即可恢复。

顶部指针固定，盘面文字随圆盘转动。连续选餐从当前位置起步；旋转高亮表示指针当前经过的扇区，最终停稳后才显示结果。长菜名可换行；编号对照保留完整内容，窄窗口允许上下滚动。极多候选会降低盘面辨认性。

“声音”开关在标题旁，首次默认关闭。开启后，点击选餐发短按钮声，转动时轻咔嗒，正常停稳并显示结果后发一次短铃声；快转会减少咔嗒密度，不排队补播。添加、删除仅在保存成功后发较轻提示；取消、失败、输入和展开收起不发成功音。

静音立即停止当前声音，打开页面不自动发声；音量受系统、浏览器及输出设备影响。开关保存在浏览器Cookie `what_to_eat_sound` 中约一年，属于本机 `127.0.0.1`，不按端口区分；同一浏览器配置重启可保留，本机其他程序副本可能共用选择。更换浏览器、隐私模式、清理网站数据或阻止Cookie后不保证记忆。

## 完整退出和重启

- 关闭启动窗口，或在该窗口按Ctrl+C；若询问是否终止批处理，输入Y并回车。再关闭网页。
- 只关闭网页不会停止程序。若开了多个启动窗口，要全部退出。
- 再次双击 `start.bat`。菜单保留；结果和角度不保存，页面回到待选状态。
- **只运行一个实例。** 程序不会阻止重复启动，多进程同时改菜单可能相互覆盖；多个页面也不会自动同步，修改后可刷新其他页面。

## 数据、备份和恢复

菜单位于**程序文件夹内的 `data/menus.json`**，是UTF-8 JSON列表。不存在时才初始化，空列表 `[]` 会保留。损坏或格式错误会停止启动并保留原文件。

1. 完整退出所有实例，确认启动窗口都已关闭。
2. 把整个 `data` 文件夹复制到程序目录以外的备份位置。
3. 在新位置准备环境、取得并解压代码，启动前把备份的 `data` 放入新程序文件夹。
4. 如果目标已有菜单，先退出并备份，再决定是否替换；不要运行中覆盖数据。
5. 启动并展开菜单，核对完整内容。撤回恢复操作时，也应先退出，再还原原备份。

从GitHub取得代码**不会带回个人菜单**。菜单备份不包含浏览器声音选择、选餐结果或角度；换电脑后可重新设置声音。工具没有自动备份、账号或云同步，个人菜单和备份不应公开上传。

## 常见问题

| 提示或现象 | 下一步 |
| --- | --- |
| 未找到可运行的Python | 按提示安装Python 3.8或更新版本，包含Launcher并配置PATH，然后重新启动。也可能是安装或命令配置异常。 |
| Python版本过低 | 窗口显示检测到的版本；安装满足要求的Python 3版本后重试。若启动器选中了旧版而PATH里有合适版本，脚本会尝试后者。 |
| 程序未能正常启动或运行 | 上方保留具体错误和退出码。检查文件是否完整、文件夹可写；保留错误信息便于排查。按任意键后关闭窗口。 |
| 菜单文件损坏或格式错误 | 先备份原文件，优先恢复有效备份；不要直接删除个人数据来重置。 |
| 启动提示资源或Windows PowerShell报错 | 确认 `startup-messages.json` 与启动文件同目录；受管理电脑若禁止Windows PowerShell，中文提示可能无法显示完整，需排查系统限制。 |
| 网页未自动打开或旧页面无法操作 | 保持启动窗口打开，复制本次URL；不要直接打开HTML或沿用旧地址。 |
| 保存失败 | 检查文件夹权限、磁盘空间和是否仅运行一个实例；删除请求结果不明确时先刷新核对，再重试。 |
| 没有声音或开关不记忆 | 检查页面开关、系统和浏览器静音及Cookie设置；选餐和菜单保存不依赖音频成功。 |
| 转盘未完成 | 请求约八秒超时，动画超出预计时长两秒会提示重试并恢复操作；刷新回待选，不恢复未完成动画。 |

## 限制和文件说明

只监听 `127.0.0.1`，不能从手机或其他电脑访问。没有多实例写入协调、编辑菜名、批量删除、排除/权重、选择历史或皮肤切换。80项经过专项检查，但任意菜单规模、所有浏览器和设备未覆盖；模拟故障不是实际断电或磁盘损坏测试。

交付内容为上述七个运行文件、`README.md`、`LICENSE` 和 `.gitignore`。运行后生成的 `data/menus.json` 需另外备份，下载包不包含个人菜单。

页面SVG图形与三种音效为本项目实现；完成铃是敲击与金属共鸣合成后的内嵌PCM，没有采用外部铃声录音，无需下载音频素材或字体文件。项目采用 [MIT 许可证](LICENSE)，Copyright (c) 2026 ITer99；使用或分发时应保留版权与许可声明。
